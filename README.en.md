# Skills

[中文](README.md)

My collection of agent skills.

## Skills

| Name | Purpose |
| --- | --- |
| [change-review](skills/change-review/SKILL.md) | Review proposed code, tests, and documentation against the change's purpose and project conventions |
| [code-simplification-review](skills/code-simplification-review/SKILL.md) | Find worthwhile refactors by tracing callers, state changes, and observable behavior |
| [guided-practice](skills/guided-practice/SKILL.md) | Guide one exercise at a time and check what the learner can do independently |
| [handwrite-page](skills/handwrite-page/SKILL.md) | Render Chinese text, English terms, and equations as handwriting on a photographed sheet of paper. [Samples and results](examples/handwrite-page/README.md) |
| [natural-writing](skills/natural-writing/SKILL.md) | Chinese and English writing, editing, and review for Codex |

## Installation

```bash
npx skills add QwQBiG/skills
```
