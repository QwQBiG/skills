# 选哪张参考图

以下样稿由同学贡献。每次选与新稿最相近的一至两张，直接作为生图的视觉输入。保留词组与相邻行的关系。

| 样稿 | 观察位置与用途 |
| --- | --- |
| [编号叙述](../assets/handwriting/numbered-prose.jpg) | 看开头的题目和第二、三行。序号贴左边，右括号和正文之间留隙。长句写到行尾，短续行留白。黑字的下缘大多搭在实线上，个别竖笔落到线下。 |
| [中英混排](../assets/handwriting/mixed-definitions.jpg) | 看前三行的 CPU、括号、斜线，再看下半部的乘号和 ALU。正文里的缩写随句子排列，定义的续行会向右缩进。 |
| [缩写对照](../assets/handwriting/abbreviations.jpg) | 看 PC、IR、I/O 和 MIPS。大写字母各自有宽窄，I 的上下横明显，P 的竖笔偏长。左栏缩写长度不一，冒号和右栏释义大致对齐。 |
| [箭头流程](../assets/handwriting/arrow-sequences.jpg) | 看下半部的取指与执行过程。短箭头位于词组中段，长度略有差异，两侧留有空隙。答与详的标签靠左，详解续行内缩。红色下划线属于那道题的批注。 |

## 写成一行时

汉字的宽窄随结构变化。对照“存储器”在不同句子中的写法，留意“存”的长撇、“储”密集的右部和“器”下部简快的转折。笔画转折处墨色较重，提笔后的细线和短点仍清晰。保留同一个词在不同位置的轻微变化。

中文夹 CPU 时，字母和汉字共用落笔线。术语可以写得紧一些，冒号后的空白、逗号和句号的宽度随上下文变化。缩写列表比连续正文疏朗。不同参考图的拍摄倍率不同，实际字高以模板的行距为准。

参考照片的蓝色偏光、背面透字、原题答案和局部下划线都属于原场景。最终纸色和光影取自所选底片，正文取自本次原稿。样本直接覆盖大写缩写、斜线、括号、乘号、数字和箭头。小写代码、花括号和复杂上下标的具体写法仍需推断，核对时单独看这些位置。
